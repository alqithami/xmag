# X-MAG-COS publication release — v1.0.0

This release packages the code and derived experimental evidence supporting:

Mohammed Alliheedi and Saad Alqithami, **“X-MAG-COS: Compact Evidence Messaging for Source-Partitioned Open-Set Intrusion Detection in 5G-IoT Networks,”** *Mathematics* (accepted, 2026; manuscript mathematics-4541032). Publisher DOI pending.

**Scope:** 5G-NIDD leave-one-attack-family-out evaluation over 8 attack families and 5 seeds; retained corrected controls; matched fixed-FPR comparison of 11 conditions; numerical quantization diagnostics; a separate CICIoT2023 transfer-stress analysis.

**Validated contents:** code, configs, aggregate and per-family evidence, 38-file SHA-256-validated supplemental archive, study fingerprint and environment record, standard-library integrity check, regression tests, and a documented real-data replay procedure.

**Excluded:** raw third-party datasets, fitted models, per-flow score arrays, private laboratory records, peer-review responses, and publisher-proof source. Obtain the required dataset separately; consult `docs/DATA.md`.

**Reproducibility claim:** reproducible *audit of publicly retained evidence* and executable replay from the specified data. We do not claim that fixed-seed training is guaranteed to be bit-identical across machines or that the public evidence alone reconstructs every historical checkpoint.

Use the tag/commit associated with this release for citations; do not cite the moving development branch.
